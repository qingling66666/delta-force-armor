# 三角洲行动 · 护甲数据库

一个纯静态的《三角洲行动》护甲/弹药数据查询站，覆盖 1–6 级防弹衣、头盔，以及口径穿透与弹甲克制关系。零依赖、零构建，双击 `index.html` 即可本地打开。

**线上地址：https://qingling66666.github.io/delta-force-armor/**

## 页面

| 页面 | 内容 |
|---|---|
| `index.html` | 首页 · 总览与入口 |
| `armor.html` | 护甲图鉴 · 1–6 级防弹衣全数据 |
| `helmet.html` | 头盔图鉴 · 1–6 级头盔全数据 |
| `ammo.html` | 弹药速查 · 口径 / 穿透等级 / 弹甲克制 |
| `compare.html` | 横向对比 · 全装备数据总表 |
| `mechanics.html` | 机制解析 · 穿透 / 减伤 / 维修 |
| `sandbox.html` | 对枪沙盘 · 配装承伤与击杀枪数推演 |
| `404.html` | 自定义 404 页 |

## 技术

- 纯 HTML + CSS + 原生 JS，无框架、无打包
- 全部使用相对路径，可直接部署到任意子目录（GitHub Pages / 静态托管 / 本地文件）
- 图片资源位于 `assets/`

## 本地预览

直接双击 `index.html`。或起一个本地服务（避免个别浏览器对本地文件的限制）：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 更新网站

改完文件后，双击仓库根目录的 `update.cmd`，自动提交并推送。GitHub Pages 约 1 分钟后重新构建。

手动方式：

```bash
git add -A
git commit -m "更新说明"
git push
```
